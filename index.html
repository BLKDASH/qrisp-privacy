QRisp 隐私政策

更新于 2026 年 11 月 24 日

QRisp 是一款离线二维码生成扩展。本政策适用于 Microsoft Edge 和 Google Chrome 上的 QRisp 1.0.1，以及 Google Chrome 上的 QRisp 1.1.0。

处理的信息与用途

  • 打开 QRisp 工具栏弹窗时，扩展通过 activeTab 读取当前标签页的标题和网址。标题和网址显示在弹窗中，网址用于生成二维码或复制链接。
  • 在 Chrome 版 1.1.0 中，contextMenus 权限用于显示「使用QRisp生成二维码」右键菜单项。只有你点击该项，QRisp 才使用浏览器提供的所选文字，在本机生成二维码。你可以在预览小窗中编辑文字、复制或下载二维码。
  • 在「自定义内容」中输入的网址或文字，用于在本机生成并预览二维码。
  • 点击复制时，扩展通过 clipboardWrite 把当前网址或 PNG 二维码图片写入系统剪贴板。点击下载时，浏览器会保存你选择的图片格式。

保存与分享

QRisp 在工具栏弹窗内临时处理当前标签页的标题、网址和自定义输入。关闭弹窗后，扩展不会保留这些内容。你主动复制或下载的内容由系统剪贴板或下载位置保留，可以自行清除或删除。

Chrome 版 1.1.0 在内存中将所选文字一次性传给对应的预览小窗。小窗接收后，后台立即清除待传文字。如果小窗创建失败，或 30 秒内未接收，后台也会清除待传内容。原文不会写入小窗网址或扩展存储。关闭小窗后，扩展不保留其中的文字。

QRisp 不会将数据传给开发者、服务器或第三方，也不会在后台记录浏览活动。扩展无需账号，不包含分析或广告，不出售用户数据。你主动分享的二维码会包含生成它时使用的网址或文字。

Microsoft Edge 加载项政策

Edge 用户可在扩展管理页（edge://extensions）停用或移除 QRisp。有关个人信息处理的要求，请参阅 Microsoft Edge 加载项开发人员政策。

Chrome 网上应用店政策

QRisp 对从 Chrome API 获取的信息的使用遵守 Chrome 网上应用店用户数据政策，包括有限使用要求。

联系

如有隐私问题，可通过 QRisp 的 GitHub Issues 联系开发者。Chrome 用户也可使用 Chrome 网上应用店的商品支持入口。
